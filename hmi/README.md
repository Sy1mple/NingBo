# 串口屏步进方向文字修复

本目录中的 `Smart_Experiment_Kit_stepper_text_fix` 是与开发板程序配套的完整串口屏工程。修复“正转／反转／停止”尾部乱码，需要重新下载此工程到串口屏。

原方向控件从 VP `1062` 读取 8 字节，存储空间与步数 `1063`、语音文本 `1064` 重叠。修复将方向控件移至独立 VP `1300`，长度设为 6 字节：两个 GB2312 汉字和 `FFFF` 结束符。开发板程序的 `STEPPER_DIRECTION` 同步改为 `0x1300`。步数、按钮、字库和状态检测控件保留原配置。

## 下载到串口屏

1. 使用原来的 VisualBoard 下载工具打开 [project.json](Smart_Experiment_Kit_stepper_text_fix/project.json)。
2. 按原来的连接方式编译并下载到串口屏。工程包含配套字库和图像，`DD_SET` 中也已包含修改后的显示文件。
3. 确认开发板程序同步到此版本，进入步进页面检查“正转／反转／停止”和剩余步数。再执行语音识别，返回步进页面检查文字尾部。

仅更新开发板、重启主服务或重启串口屏服务，不能改写串口屏内部工程。旧屏幕工程仍读取 `1062`，配套程序已改为写入 `1300`，因此两端必须一起更新。

显示文件 `DD_SET/14ShowFile.bin` 仅修改方向控件的三个字节，工程 JSON 同步修改其 VP 和文本长度；所有控件的 VP 范围已检查，新空间无重叠。该工程来自本地已保存的 `Smart_Experiment_Kit`，不包括编辑器未保存的修改。

开发板部署包也保存于 `/opt/ningbo/hmi/Smart_Experiment_Kit_stepper_text_fix.zip`。将包存入开发板不会自动下载到串口屏。

## 验证

在开发板隔离目录运行的 31 项步进显示、步进检测测试全部通过。内存模拟覆盖方向、步数和语音交错更新，结束符未被覆盖；实屏效果待配套工程下载后验证。

额外执行串口屏隔离测试时，旧烟雾测试 `test_smoke_diagnostic_request_after_screen_restart_keeps_same_uart` 失败；在未修改的原版代码上复测同样失败。本次未修改烟雾逻辑或该测试。
